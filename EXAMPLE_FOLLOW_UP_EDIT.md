# Follow-up Edit and Text-Only Consultation

## Targeted Edit Input

```text
Change the hat in the previous icon to the dark blue hat from the source image. Keep everything else unchanged.
```

## Expected Behavior

Using the visible generated image and source image, edit only the hat and any directly necessary connection area. Preserve all other character traits, the two black capsule eyes, the absence of nose and mouth, the composition, and the background.

Call the image editing tool and inspect the actual result. If the source image or existing icon is unavailable, ask the user to upload it again.

## Text-Only Consultation Input

```text
What is the required eye aspect ratio? Make the prompt clearer.
```

## Expected Behavior

Answer in text that the upright capsule eyes use a height-to-width ratio of about 2.5:1 to 3:1. Provide the requested prompt revision without generating an image and without claiming to have inspected a new result.
